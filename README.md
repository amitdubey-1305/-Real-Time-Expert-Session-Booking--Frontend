# Project Title  - 
Real-Time Expert Session Booking Platform

## Project Overview -
 This is a secure full-stack MERN application where users can register, login, browse experts, and book sessions securely using JWT authentication.

## Features - 
User Authentication
JWT Login
Protected Booking
My Bookings Dashboard
Auto-filled User Details
Responsive UI
Secure Password Hashing
